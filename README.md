# Zavi PvP Help

Crosshair turns green when you can hit an enemy!

## Features

✅ **Green Crosshair** - Turns green when a player/entity is in your attack range (3 blocks)
✅ **Normal Crosshair** - Stays white when no target is in range  
✅ **Auto Detection** - Works automatically, no config needed

## Installation

1. Put JAR in mods folder
2. Launch with Fabric
3. Done!

## How It Works

When you look at an enemy that's within 3 blocks (your attack range), the crosshair turns GREEN. When the enemy is too far away, it stays NORMAL (white).

Perfect for PvP! 🐸
